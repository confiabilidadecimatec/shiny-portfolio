Software restrito / solução comercial

RAM Analysis Software

O RAM Analysis Software é uma solução completa para aplicações comerciais, projetos técnicos e estudos avançados. A reprodução percorre automaticamente os Módulos Gerais e depois os Módulos Avançados, reiniciando o ciclo ao final.

Módulo Geral 01

Árvore de Falhas

Apresenta o módulo de Fault Tree Analysis, permitindo estruturar eventos básicos, eventos intermediários e evento topo por meio de relações lógicas.

Ferramentas online

Aplicações disponíveis para uso remoto

Além do RAM Analysis Software, este HUB disponibiliza aplicações online que podem ser acessadas diretamente pelo navegador para análises específicas de confiabilidade, falha sob demanda e otimização de manutenção.

📈

Análise de Confiabilidade – Weibull

Modelagem de dados de falha com distribuição de Weibull, curvas de confiabilidade, taxa de falha, vida característica, percentis e suporte a dimensionamento amostral.

PFDemand – Probabilidade de Falha sob Demanda

Cálculo de PFD(t), PFDavg e análise por Fault Tree Analysis com combinação de eventos por portões lógicos AND/OR.
